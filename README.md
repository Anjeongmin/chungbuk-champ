# 충북챔 — 나에게 맞는 충북 여행 처방

졸업전시용 모바일 웹 프로토타입. 진단(나이대 → 인체도 → 증상 → 문진 5문항) → 처방 조제 → 처방전(스크롤 끝 도장) → 처방 장소 담기 → 여행지 상세.

## 파일
- `index.html` · `style.css` · `app.js` — 화면과 동작
- `data.js` — **문구·질문·증상별 처방·장소 데이터 (여기만 고치면 돼요)**
- `assets/` — 이미지

## 피그마에서 뽑아 넣을 이미지 (선택)
없으면 색 배경으로 대체돼요. 아래 이름 그대로 `assets/`에 넣으면 자동 적용.

| 파일명 | 피그마 레이어 (처방 장소 선택 / 여행지 상세 화면) |
|---|---|
| `place-1.png` ~ `place-4.png` | 장소 카드 아이콘 4개 (PNG 2x) |
| `photo-1.jpg` ~ `photo-4.jpg` | 여행지 상세 상단 사진 (가로 800px 정도 JPG) |
| `mole.svg` | 두더지 (지금은 임시로 다시 그린 것 — 3D 두더지로 교체 시 같은 이름의 PNG로 넣고 `app.js`의 `mole.svg`를 바꾸기) |

## 배포 (GitHub Pages)
Settings → Pages → Branch: `main` / `(root)` → Save. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 으로 열려요.
